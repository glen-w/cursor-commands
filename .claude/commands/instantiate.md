# Instantiate templates into a project (/instantiate)

Copy the slash-command templates from this repo into a consuming project's commands directory, then fill every `__TOKEN__` from that project's card.

Read [AGENTS.md](../../AGENTS.md) and follow its **Instantiate (SOP)** section exactly. That section is the only copy of the procedure.

The target repo is the path after the command in the user's message. If none was given, ask once and stop.

This command belongs to this template repo. Do not copy `instantiate.md` into product repos.
